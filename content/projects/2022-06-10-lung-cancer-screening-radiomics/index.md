> ⚠️ **This project is no longer maintained.** It has been superseded by [qradiomics](/projects/2026-05-17-qradiomics/), which provides a unified modern Python implementation.

A comprehensive framework for lung cancer screening radiomics using LIDC-IDRI and LUNGx dataset.

- Data preprocessing - download data, conversion, etc.
- Radiomics feature extraction including spiculation features
- AutoML model building and validation

Source code [https://github.com/taznux/LungCancerScreeningRadiomics](https://github.com/taznux/LungCancerScreeningRadiomics)
